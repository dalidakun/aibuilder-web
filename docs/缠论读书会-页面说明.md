## 正文注释（跨用户，按段落聚合）

在阅读页选中任意文字即可写注释，**不需要登录**：

- 选中文字 → 浮出「✎ 注释」→ 写注释；**署名自动取头像菜单 →「我的名字」**（没设置就用账户名，
  再没有就是「匿名读者」），弹层里只读，不能直接改
- 注释按课存在云数据库 `chanAnnotations`，用 `lessonNo`（1–108）区分，
  **一课一份，互不混淆**
- **注释按段落聚合**：某一段里有注释，这一段末尾就浮出一个小按钮「注 N」，
  一个段落只有一个入口，段内所有读者的注释都在这一处
  - 点按钮 → 右侧展开这一段所有注释，**再次点同一个按钮收起**
  - 浮层从顶部菜单下沿一直伸到屏幕底部：桌面右侧 380px、手机整屏；
    内嵌 iframe 时顶部菜单在 iframe 外面，浮层就从 iframe 顶边开始
  - 标题 / 小标题上写的注释，入口就显示在标题末尾，不会掉到第一段
  - 点另一段的按钮直接切到那一段；点浮层外面、按 Esc 也能收起
  - 右上角「↻」强制刷新；浮层里不显示段落开头的原文
- 浮层里每条：**上面是选中的原文，下面是注释内容**，带署名、时间、「定位」和（自己的）「编辑」「删除」；
  编辑只改注释内容和署名，原文锚点不动，保存后带一个「已编辑」小标
- 写 / 编辑注释的弹层可以按住标题栏拖动（限制在屏幕内）；只能点右上角「×」（或「取消」/ Esc）关闭，
  **点弹层外面不会关**，避免写到一半误点丢失
- 弹层底部「署名」显示 `我的名字`（不带 @），只读；要改名字去右上角头像菜单 →「我的名字」。
  自己的旧注释也会用当前名字显示；改名后服务端会把本人历史注释 / 提问 / 回复的署名一起改掉
- 只有自己写的注释才有「编辑」「删除」，别人的注释只能看和定位
- **画线只画自己的**：正文里的浅绿色标记只标出本浏览器自己写的注释，别人的注释不铺在正文上；
  但段落入口的「注 N」、浮层里的列表和计数始终是**全量**（本课所有读者）
- 自己写过的文字点标记 → 展开所在段落的浮层并把这条滚进视野；
  别人的注释点浮层里的「定位」→ 滚到它所在的那一段，并让段落入口闪一下
- 原文改动后定位不到的旧注释不会丢：统一挂到正文末尾的「更早的注释」里，
  浮层标题也显示「更早的注释」
- 段落入口按钮**不放文本节点**（计数用 CSS `::after` 画），所以加按钮不会改变
  正文的「文本流偏移」，注释锚点始终稳定
- 匿名身份是浏览器本地生成的 `clientId + secret`（localStorage `chan:anno:*`）；
  删除由服务端用 `clientHash` 校验，只能删自己写的那条
- 接口（`cloudfunctions/api/index.js`）：`getChanAnnotations` / `createChanAnnotation` /
  `updateChanAnnotation` / `deleteChanAnnotation`。匿名可读、可写；读接口按课返回
  （默认 300 条，最多 500 条）；同浏览器 10 分钟最多发 20 条（轻量频控）。
  编辑和删除一样要校验 `clientId + clientHash`，只能改自己那条
- 锚点存「课内文本流偏移」`anchor:{s,e}`，换设备、换字号都能定位；原文若改动，
  客户端会退回用 `quote` 在课文里重新查找
- 前端在 `site/assets/js/chan-annotations.js`，样式在 `site/assets/chan.css`
- **省成本**：每课注释在浏览器本地缓存 5 分钟（`localStorage` 的
  `chan:anno:cache:<lessonNo>`，最多保留 20 课）。刷新页面、切回本课、打开浮层
  都不会重复请求云端；点浮层右上角「↻」才强制刷新；发布/编辑/删除后同步更新本课缓存。
  缓存按 `lessonNo` 分开存，**课与课互不混淆**

## 每课提问（可附图）

- 每篇文章末尾一块「提问」区（原「评论」），按 `lessonNo` 归属，**课与课互不混淆**
- 每条提问/回复左侧显示用户**自己上传的头像**（读账号资料里的头像 `tradeAvatarGet`，
  存到 `chanProfiles` 按 clientId 关联）；没上传过就显示绿色首字默认头像
- 提问框只有输入框、「添加图片」和「发布提问」，不单独要求填用户名；
  署名自动取头像菜单 →「我的名字」，没设置就用账户名，再没有就是「匿名读者」，列表直接显示姓名（不带 @）
- **提问和回复都可以附图**，最多 3 张，也可以只发图片、不写字：
  - 图片在浏览器里先压：长边 1600px、铺白底、JPEG 0.78 起，优先保清晰度，按体积继续降质量；
    单张压到约 22 万字符以内、合计约 66 万字符以内才上传
  - 选完图先在输入框里显示 64px 缩略图，可逐张删除；列表里只显示 88px 缩略图，
    点缩略图放大后可以用左右按钮 / ← → / 手机左右滑动查看同一组里的其它图片
  - 服务端再兜底：最多 3 张、单张 ≤24 万字符、合计 ≤70 万字符，
    只接受 `data:image/(jpeg|png|webp);base64,` 前缀
  - `getChanComments` 单次返回的图片总预算 2MB 字符；超额时较早的提问只回文字，
    带 `imagesHidden`，前端显示「图片已省略（较早的提问）」，避免一次读拖回几十 MB
- 任何用户都能提问、回复；楼中楼只做一层，回复的回复也挂到主楼
- **只有管理员能删除/置顶**：普通用户每条提问只看到「回复」按钮；管理员可删除任意提问、置顶/取消置顶主楼
- **删除后彻底不显示**：`getChanComments` 不再返回已删除提问，主楼删掉时它下面的回复一并消失，页面不出现「该提问已删除」占位
- 匿名身份与正文注释共用 `clientId + secret`；管理员存在 `chanAdmins`，
  记录 `clientId + clientHash`（sha256(clientId + "\n" + secret)）
- **randeng 已是管理员**：绑定的是写注释那个浏览器的身份
  `1fca961f4ebadce4b54554af`。在同一个浏览器打开读书会，提问区会显示「管理员」徽标；
  换设备需要再往 `chanAdmins` 插一条新的 clientId/clientHash
- 接口（`cloudfunctions/api/index.js`）：`getChanComments` / `createChanComment`
  （新增可选 `images` 数组） / `deleteChanComment` / `pinChanComment` / `saveChanAvatar`；
  改名用 `updateChanDisplayName`（按 `clientId` 批量改本人历史注释 / 提问 / 回复的署名）
- 集合：`chanComments`（一条提问一个文档，`parentId` 为空是主楼，`images` 存压缩后的 data URL）、
  `chanAdmins`、`chanProfiles`（`_id` = clientId，存用户头像 data URL）
- 前端在 `site/assets/js/chan-comments.js`；每课提问本地缓存 60 秒，右上角「↻」立即刷新
- **消息提醒**：管理员和普通用户都从左上角账户头像进入「查看消息」；
  管理员看到全部未处理消息，普通用户看到自己参与过的提问楼层里的新回复（包括别人互相回复）
- 新消息每 25 秒轮询一次（`getChanMessageInbox`），头像左上角和「查看消息」菜单项都有红色角标
- 打开消息汇总**不会自动清掉**：每条未回复消息旁有「标记已读」，点后才会从下次列表消失；
  已经回复过的消息由服务端自动视为处理完，下次不再出现；没处理的继续保留
- 汇总框里可直接回复（可附最多 3 张图片），也可以点消息跳到对应第 N 课定位原提问；只有右上角 × 能关闭
- 消息汇总里的回复输入框使用浅黄底色，不加白色圆角背景
- 提问区在正文之外，选中提问文字不会触发正文注释；正文注释的锚点也会跳过提问区

`tcb fn code update` 不会动云函数的环境变量，别用 `tcb fn deploy`（会按本地配置覆盖）。

## 教学白板（右上角悬浮按钮）

阅读页右上角有一个「白板」悬浮按钮，点开是一块整屏教学白板：可以画笔、写粉笔字、
画几何图形、贴图。**内容自动存在本机浏览器，不上传服务器**，也可以导出 PNG 或工程 JSON。
现在**不再分页**，一块白板从上边界开始一路往下延伸。

- 入口：`site/chan.template.html` 的 `#cwbLaunch` / `#cwbOpen`
  - 桌面是带「白板」字样的悬浮胶囊，和阅读工具条的「A+」在同一行；≤1180px 只留图标
  - ≤960px 按钮仍在顶部阅读工具条这一行（工具条右侧留 50px），≤720px 跟着 40px 的顶栏上移
  - 打开 / 收起用 `clip-path: circle()` 从按钮中心向整页圆形展开 / 收回；按钮 z-index 在面板下面
  - 嵌在首页 `index.html#chan` 的 iframe 里时，打开白板会给父页面 `html` 加 `chan-wb-open`：
    父页面顶栏隐藏，`page-viewport` 临时 fixed 铺满整屏，白板 iframe 从 `y=0` 开始占满 100vh；
    关闭时立即移除这个 class，父顶栏马上恢复，不会等关闭动画结束才出现。
  - 白板自己的工具栏整体固定在**底部**（标题 / 颜色 / 工具 / 背景 / 保存 / 导出在 iframe 内）；
    关闭叉号单独浮在**右上角**，只有一个图标、不带底色。
- 面板：`#cwb` 整屏对话框在 `chan.template.html` 里；样式 `site/assets/chan-whiteboard.css`，
  逻辑 `site/assets/js/chan-whiteboard.js`（原生 JS，无第三方依赖）
- 底部工具栏：标题、13 个绘图工具、颜色圆点、白/黑背景、扩展按钮、保存状态 / 导出；

  - 标题默认是当前**年月日时**（如 `2026-11-18 16时`），点标题可改名；标题按钮占满左侧空间
  - 旧数据里的「白板 1 / 白板 2」这类默认名会迁移成当前年月日时
  - 13 个工具全部收进底部工具栏；颜色直接铺在工具栏里（9 色 + 自定义），不再折叠；

  - 旧背景里的米黄 / 浅绿 / 浅蓝 / 浅灰 / 方格 / 点阵 / 横线，读取时统一迁移成白色

  - 图片 / 文字拖到上 / 左 / 右边界就停（整组按包围盒钳制），不会滑到边界外被裁掉；

- 「阶段图」从该阶段本金起画，只留一条虚线基准，不写文字

**收益率口径**：单笔收益率 = 这笔盈亏 ÷ 这笔之前的余额；阶段收益率 =
（阶段期末余额 − 阶段初始本金）÷ 阶段初始本金。
